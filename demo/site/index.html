    STAGE 3

    INSTRUCTION MANUAL

    Four power-ups that make it fast. No trees, no heap allocation per order, no locks.

    BITSET RADAR
    BEST PRICE: O(1) · NEXT BEST: 1 READ PER 64 TICKS

    One bit per price level. When the best level empties, the next one is found with countr_zero on 64-bit words instead of checking levels one by one.

    FIFO TRAIN
    ADD: O(1) · CANCEL ANYWHERE: O(1)

    Each price level is a doubly linked queue threaded through the 32-byte orders themselves. New orders couple on at the back, fills leave from the front, cancels unhook from anywhere.

    ITEM POOL
    MALLOC ON HOT PATH: 0

    Every order slot exists before the first order arrives. A LIFO free list hands back the slot freed most recently, which is still warm in cache.

    SPSC LOOP
    LOCKS: 0 · CAS: 0 · 19M MSGS/S

    The gateway thread drops orders into a ring, the matching thread picks them up. Head and tail live on separate cache lines and sync with acquire/release only.

    2,000,000
    ORDERS REPLAYED AGAINST A REFERENCE BOOK. 0 MISMATCHES.

    A randomized differential test checks every result code, every trade, every queue order by order, and the full depth of both sides against the std::map book. CI runs it on GCC and Clang.
