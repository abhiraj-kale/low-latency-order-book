    03 / Inside

    Four ideas doing the work

    No trees, no per-order heap allocation, no locks. Each structure below is animated with the same behavior the engine uses.

    Occupancy bitset

    One bit per price level. When the best level empties, the next best price comes from countr_zero on 64-bit words, so a gap of 1,000 empty ticks costs about 16 reads.

    Intrusive FIFO per level

    Orders at a price form a doubly linked queue threaded through the 32-byte orders themselves, using 32-bit indices. Cancel from anywhere is O(1) and fills always take the oldest first.

    Preallocated pool

    Every order slot exists before the first order arrives. A LIFO free list hands back the most recently freed slot, which is still warm in cache. Nothing calls new on the hot path.

    Lock-free SPSC ring

    The gateway thread and the matching thread share a ring with head and tail on separate cache lines. Acquire/release ordering only, no locks, no compare-and-swap: 19M msgs/s end to end.

    Checked against a reference book, trade by trade

    A randomized differential test replays 2 million orders through both the engine and the std::map book. Every result code, every trade (maker, taker, price, quantity), and the full depth of both sides must match exactly. CI runs it on GCC and Clang.
